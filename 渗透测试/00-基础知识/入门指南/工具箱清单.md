## 2. 信息收集工具

### 2.1 Nmap (端口扫描)

```bash
# 安装
sudo apt install nmap

# 基础扫描
nmap target.com
nmap -sS -sV -O target.com

# 全端口扫描
nmap -p- target.com

# 脚本扫描
nmap --script=vuln target.com
```

### 2.2 子域名枚举

```bash
# Sublist3r
git clone https://github.com/aboul3la/Sublist3r.git
pip install -r requirements.txt
python sublist3r.py -d target.com

# Amass
sudo apt install amass
amass enum -d target.com
```

### 2.3 目录扫描

```bash
# Dirsearch
git clone https://github.com/maurosoria/dirsearch.git
python3 dirsearch.py -u http://target.com

# Gobuster
sudo apt install gobuster
gobuster dir -u http://target.com -w wordlist.txt
```

## 4. Web渗透工具

### 4.1 Burp Suite

```bash

# 配置代理

# 常用功能
- Proxy: 抓包
- Repeater: 重放
- Intruder: 爆破
- Scanner: 扫描 (Pro版)
```

### 4.2 SQLMap

```bash
# 安装
sudo apt install sqlmap

# 基础使用
sqlmap -u "http://target.com/page?id=1"
sqlmap -u "http://target.com/page?id=1" --dbs
sqlmap -u "http://target.com/page?id=1" -D dbname --tables
sqlmap -u "http://target.com/page?id=1" -D dbname -T users --dump

# POST请求
sqlmap -u "http://target.com/login" --data="user=admin&pass=123"
```

## 7. 密码攻击工具

### 7.1 Hydra (在线爆破)

```bash
# 安装
sudo apt install hydra

# SSH爆破
hydra -l admin -P passwords.txt ssh://192.168.1.100

# FTP爆破
hydra -L users.txt -P passwords.txt ftp://192.168.1.100

# HTTP POST
hydra -l admin -P passwords.txt 192.168.1.100 http-post-form "/login:user=^USER^&pass=^PASS^:F=incorrect"
```

### 7.2 John the Ripper (密码破解)

```bash
# 安装
sudo apt install john

# 破解
john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt

# 查看结果
john --show hashes.txt
```

### 7.3 Hashcat (GPU加速)

```bash
# 安装
sudo apt install hashcat

# MD5破解
hashcat -m 0 -a 0 hashes.txt wordlist.txt

# NTLM破解
hashcat -m 1000 -a 0 hashes.txt wordlist.txt
```

## 10. 常见错误解决

### 10.1 权限问题

```bash
# 错误: Permission denied
# 解决
sudo chmod +x tool.sh
sudo chown $USER:$USER tool.sh
```

### 10.2 依赖问题

```bash
# 错误: ModuleNotFoundError
# 解决
pip install -r requirements.txt
sudo apt install python3-dev
```

### 10.3 网络问题

```bash
# 错误: Connection timeout
# 解决
# 1. 检查防火墙
sudo ufw status

# 2. 检查代理
unset http_proxy
unset https_proxy

# 3. 检查DNS
ping 8.8.8.8
```

## 工具使用技巧

### 快速启动脚本

```bash
#!/bin/bash
# tools.sh

case $1 in
  "nmap")
    nmap -sS -sV -O $2
    ;;
  "dirsearch")
    python3 ~/tools/dirsearch/dirsearch.py -u $2
    ;;
  "sqlmap")
    sqlmap -u $2 --batch
    ;;
  *)
    echo "Usage: ./tools.sh [nmap|dirsearch|sqlmap] <target>"
    ;;
esac
```

### 工具更新脚本

```bash
#!/bin/bash
# update-tools.sh

echo "[*] Updating system..."
sudo apt update && sudo apt upgrade -y

echo "[*] Updating Metasploit..."
sudo msfupdate

echo "[*] Updating Nuclei templates..."
nuclei -update-templates

echo "[*] Done!"
```
