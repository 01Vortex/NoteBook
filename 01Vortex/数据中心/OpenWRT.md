### 数据流关键步骤总结

| 步骤 | 位置 | 动作 | 数据形式 |
|------|------|------|----------|
| ① | 客户端 | 用户请求访问 NAS `192.168.8.10` | 明文 IP 包: `10.0.0.2 → 192.168.8.10` |
| ② | 客户端 | WireGuard 加密并 UDP 封装 | UDP 包: `客户端公网IP:随机端口 → 路由器公网IP:51820`，载荷加密 |
| ③ | 互联网 | UDP 包透明路由 | 不变 |
| ④ | 路由器 WAN | 接收 UDP 包 | 同上 |
| ⑤ | 路由器内核 | WireGuard 解密 | 还原明文 IP 包 `10.0.0.2 → 192.168.8.10` |
| ⑥ | 路由器路由表 | 查询目标 `192.168.8.10` | 接口为 `br-lan` |
| ⑦ | 防火墙 | 检查 `wg0 → lan` 区域策略 | 允许转发 |
| ⑧ | 路由器 LAN | 从 `br-lan` 发出 | 明文 IP 包同上 |
| ⑨ | 内网 NAS | 收到请求并处理 | 生成回包 `192.168.8.10 → 10.0.0.2` |
| ⑩ | 路由器 LAN | 回包进入，路由表指向 `wg0` | 明文 IP 包 |
| ⑪ | 路由器内核 | WireGuard 加密，UDP 封装 | UDP 包: `路由器公网IP:51820 → 客户端公网IP:随机端口` |
| ⑫ | 客户端 | 解密并交付上层应用 | 还原回包 |

---

### 核心要点

- **隧道只保护客户端 ↔ 路由器这一段**：内网设备 (`192.168.8.x`) 并不需要安装 WireGuard，它们发送的是普通 IP 包。
- **路由器充当“协议转换器”**：它接收加密的 VPN 流量，解密后当作本地 LAN 流量转发；回程时则重新加密。
- **无需 SNAT**：当访问内网设备时，路由器**不做源地址转换**，因为 `10.0.0.2` 并不需要伪装成 `192.168.8.1`，内网设备通过路由表就能把回包正确送回路由器（路由器知道 `10.0.0.2` 在 `wg0` 侧）。
- **防火墙是关键**：必须显式允许 `wg0` 区域转发到 `lan` 区域，否则即使路由正确也会被丢弃。
